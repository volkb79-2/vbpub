# pwmcp CLI specification

Canonical command-line contract of the `pwmcp` console script shipped in the
`pwmcp-client` wheel (`client/`). The generated grammar inventory between the markers
below is owned by `cli-extended surface sync`; everything else is product-owned. The
user-facing guides are [`README.md`](../README.md) and [`USAGE.md`](USAGE.md); the
reviewed semantic decisions and their linked tests are in
[`cli-review.toml`](cli-review.toml), and review findings in
[`cli-review-findings.toml`](cli-review-findings.toml). The surface is declared in
[`../client/pyproject.toml`](../client/pyproject.toml) (`[tool.cli-extended]`). Adoption record and acceptance evidence:
[`PWMCP-02-REPORT.md`](PWMCP-02-REPORT.md).

The `inspect` route is the PWMCP-01 addition. Its generated grammar is included
below, and its active behavioral review cases link to the R1 gate tests.

## Caller surfaces

| Surface | Caller | Contract |
| --- | --- | --- |
| `pwmcp` (console script, `pwmcp_client.cli:main`) | operator or agent in a consumer container, devcontainer, CI | the registered CLI below; needs the `cli-extended` wheel (declared dependency) |
| `python -m pwmcp_client.cli` | tests | same registered CLI as the console script |
| `pwmcp_client` Python API (`BrowserLease`, `load_contract`, ...) | consumer test suites | a library, not a CLI; unchanged |
| `build-push.py`, `scripts/build-bundle.py`, `scripts/publish-bundle.py`, `scripts/resolve-playwright-version.py` | CMRU release steps (`cmru.toml`) | internal, single-command CLIs on the same library (`scripts/_vars.py` `script_cli`); not operator CLIs, so not catalogued here |

## Semantic table

| Verb | Use case | Selection and omission | Effects | Dry run / confirmation | Exit status |
| --- | --- | --- | --- | --- | --- |
| `contract` | print the server contract a consumer must match (release, Playwright version, endpoints, limits) | `--contract URL_OR_FILE` (default `http://pwmcp:3000/contract`); global, accepted before or after the verb | one HTTP GET (10 s timeout) or a file read; prints indented, key-sorted JSON (`--json`: the same object on one line) | none: read-only | 0; 1 contract unreachable or malformed (`[ERROR]` line, no traceback); 2 usage |
| `versions` | print the client version and, when reachable, the server release plus the skew verdict (`pwmcp 1.64.1.post2 (server 1.64.1-r2)`, or `(server unreachable)`); `--version`/`version` stay the shared CLI's exact network-free `pwmcp <version>` line | `--contract URL_OR_FILE`; global | read-only: one contract fetch/read; WARN on stderr when the pair differs | none: read-only | 0 always (also when the server is unreachable); 2 usage. The client version is the server release mapped to PEP 440 (`-rN` -> `.postN`); compatibility: same Playwright major.minor = compatible (WARN on a different patch or `-rN`), different major.minor = FAIL (see `doctor` check `skew` and README "Client install and upgrade") |
| `inspect` | inspect a rendered webpage through the remote PWMCP browser | required absolute HTTP(S) URL; `--format {text,snapshot,html,markdown,links,screenshot}` (default `text`); `--main` or `--selector CSS` for content extraction; `--wait-until {commit,domcontentloaded,load,networkidle}` (default `load`); optional `--wait-for SELECTOR`, `--timeout-ms N`, `--output PATH`, `--full-page`, `--ignore-https-errors`, and `--allow-http-error`; global `--contract` selects the contract source | opens a managed `BrowserLease` and temporary browser context, navigates remotely, and emits the selected rendered format; `--json` always uses the object envelope `content`, `diagnostics`, `format`, `http_status`, `http_error`; screenshots are written to a `.png`, `.jpg`, or `.jpeg` file; the opt-in TLS bypass applies to HTTPS requests from any host in that context | no dry run; remote navigation is read-only, optional `--output` writes the named local file | 0; 1 invalid URL, unavailable PWMCP/Playwright, navigation or output failure (`[ERROR]` line); 2 usage; 4 recognized bot protection; 5 main-document HTTP 4xx/5xx unless `--allow-http-error` |
| `eval` | evaluate a JavaScript expression or function in the remote page and print its JSON value | required absolute HTTP(S) page URL and expression, or `--selector` with `--attr`/`--property`; `--all`, `--timeout`, `--max-bytes` (1..4194304, default 1 MiB), and `--allow-http-error`; global `--json` returns the same object envelope with `format: "eval"` | navigates and evaluates through the existing MCP tools; checks the compact JSON byte cap in the page before the MCP response; connects directly to `PWMCP_MCP_URL`, ignores proxy environment variables, and refuses MCP redirects | none: no dry run or confirmation; page code can change page state and make requests | 0, including a truncated preview (text marker on stderr); 1 invalid URL or MCP/size failure (`[ERROR]` plus a size hint for response overflow); 2 usage; 5 main-document HTTP 4xx/5xx unless `--allow-http-error` |
| `ocr` | recognise text in an image or a page element through the OCR sidecar (PWMCP-11 phase 1): text, per-word confidence and boxes, never a decision | exactly one of `--image PATH\|-` (PNG/JPEG file or stdin) or a page URL with required `--selector CSS` (optional `--region x,y,w,h`, `--wait-ms N`, `--ignore-https-errors`); `--engine` (default `tesseract`), `--lang` (`eng`), `--psm {3,4,6,7,11,13}` (`6`), `--scale N` (`1`), `--whitelist CHARS`, `--min-conf N` (`0`; FLAGS words below N as `low_conf` and warns, never removes them: the text is always complete), `--timeout-ms` (`30000`); `--sidecar-url` else `$PWMCP_OCR_URL` else the contract's `ocr_url`; `--format {text,json,tsv}` (default `text`, global `--json` implies `json`, contradicts `tsv`); `--output PATH` | URL form: opens a fresh browser context like `inspect` (server-level user agent applied), captures the element or region as PNG, closes context and lease; both forms: one HTTP POST of the image to the sidecar; prints the result to stdout or writes `--output`; never sends keys | none: read-only | 0; 1 sidecar refused or unreachable, capture or output failure (`[ERROR]` line); 2 usage, or no sidecar URL known (message names `ocr.enabled`) |
| `doctor` | verify the consumer environment against the server | `--check NAME` (repeatable; `contract`, `playwright`, `skew`, `skills`) selects checks, default all | read-only: contract fetch/read, installed-package metadata, skills install state | none: read-only | 0 no `fail`; 1 any check failed; 2 usage |
| `skills install` / `uninstall` | install or remove the packaged `pwmcp-fetch` agent skill for Claude and agents harnesses | `--harness` or `--dest DIR`; default all harnesses | writes or removes skill directories under the chosen destination only | `--dry-run` previews; `--yes` is not offered (the library's skills group never prompts) | 0; 1 refused (modified skill without `--overwrite-modified`); 2 usage |
| `skills check` / `list` | report whether the installed skills match the wheel | same target options | read-only | none: read-only | 0 current; 1 stale, modified, foreign or leftover (`check`); 2 usage |
