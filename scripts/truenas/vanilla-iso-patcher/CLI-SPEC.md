# TrueNAS vanilla ISO patcher CLI specification

The generator discovers installer images with `.sha256` sidecar links from
both official TrueNAS indexes, downloads exact selected versions after
verifying their published SHA-256, and can build one of three flavors from
either that upstream image or a local ISO with a caller-supplied expected
SHA-256: `bounded` preserves the regular installer flow, `unattended` installs
to one safe disk or a matching two-disk mirror, and `unattended-relaxed` also
applies an experimental, exact-release boot-pool adapter on two pinned v27/v28
images. Creation also emits a VCDIFF patch and a manifest for the Windows apply
script.

Both unattended flavors erase accepted target disks without confirmation and
set the initial `truenas_admin` password to `truenas`. A disk inventory outside
the one-disk or matching-pair policy stops before the installer wipes anything.

The catalogue is intentionally limited to installer versions numbered 25 or
later. That keeps the explorer focused on current SCALE-era installers while
the ISO patcher still validates the embedded installer source and refuses an
unsupported layout before editing it. The release version itself is not
treated as compatibility proof.

`create` refuses output-path collisions and asks for confirmation before
download, SquashFS rebuild, delta generation, and publication. Non-interactive
automation must pass the shared `--yes` option. A local source ISO requires
`--expected-input-sha256`; upstream sources use the SHA-256 sidecar published
with the ISO. The Windows script requires the generated `<delta>.json`
manifest, validates source, delta and reconstructed output hashes and lengths,
and never overwrites an existing output ISO.

- `route:entrypoint:truenas-vanilla-iso/create`:

  - --upstream-version and --expected-input-sha256 cannot be used together: the published checksum is fetched for upstream releases

  - --post-install-action requires --flavor unattended|unattended-relaxed: post-install actions apply only to unattended installer flavors
