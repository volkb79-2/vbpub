# `monitor-task` CLI specification

This is the canonical grammar and semantic specification for the installed
`monitor-task.py` command. The executable `build_cli()` registry defines
argparse syntax and dispatch. [`cli-review-monitor-task.toml`](cli-review-monitor-task.toml) retains
product decisions and behavioral test links. Regenerate the marked section and
machine manifest from the repository root using the workflow in
[`cli-extended`'s consumer guide](../../libraries/cli-extended/docs/CONSUMERS.md#adopt-the-generator).

The operator contract is intentionally split into two verbs: `show` retrieves
one task snapshot; `watch` polls the task to a terminal provider state. The
`watch` interval is finite and positive, and `--poll` belongs only to `watch`.
Task UUID validation occurs before credential or API setup. JSON is available
on `show` and redacts sensitive fields by default; `--debug-raw` is an explicit
diagnostic opt-out that can reveal secrets and warns when active. These choices
are recorded below with the invocation and effect oracle for each generated
case.
