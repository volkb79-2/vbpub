# `install-restore-iso` CLI specification

This documents the high-level Netcup SCP workflow for uploading and booting a
custom restore ISO, then detaching provider media and verifying disk boot.
`install-restore-iso.py` delegates all provider operations to the shared SCP
client. Its private workflow checkpoint supports a separate restore-completion
handoff so an ISO is not detached before the guest has finished writing its
target disk.
