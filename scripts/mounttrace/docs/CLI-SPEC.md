# mounttrace CLI specification

Canonical command-line contract for the installed `mounttrace` console script.
The analysis itself remains a standard-library-only module; this document and
the generated region cover only the cli-extended adapter that operators invoke.

## Product semantics

Every verb is read-only. None mounts, unmounts, enters a namespace, executes a
child process, or changes inspected filesystems. `--no-probe` disables path
resolution, `stat`/`lstat`/`readlink`, and btrfs ioctls; `soulmask` still reads
its explicitly selected state file. With `--watch`, the selected mount tables
and Soulmask state are re-read after the interval, one report is emitted per
change, and Ctrl-C returns the most recent report status.

Path selectors use `[PID:]PATH`: a plain absolute path means the invoking
process's root and mount namespace, while `PID:PATH` names another process's
view. The analysis does not enter that namespace.

| Verb | Input | Result and exit status |
| --- | --- | --- |
| `explain` | one `[PID:]PATH`; optional `--submounts` | Writes route, mount ancestry, and hidden mounts; 0 even when findings are informational. |
| `compare` | one reference plus at least one other `[PID:]PATH` | Object identity across views; 0 when all agree, 3 when any differ. |
| `audit` | one absolute host prefix and one `PID:PREFIX` | Mountpoint set and object identity below both prefixes; 0 when clean, 3 on an alert. |
| `predict` | one absolute future host mountpoint and at least one PID | Propagation into selected views; 0 for an observation. |
| `soulmask` | at least one PID, optional state file and volumes root | Soulmask state plus live volume audit; 0 when clean, 3 when state or mounts disagree. |

Human output uses at most the selected terminal width (120 columns when no
usable terminal width exists), with `-v` or the library-owned `--verbose` /
`--debug` expanding collapsed detail. JSON is one compact object per pass and
one NDJSON object per emitted pass under `--watch`; its schema and field
ordering are the machine contract.

Usage errors exit 2. Operational failures, including unreadable or vanished
selected processes, exit 1. Unexpected exceptions use the cli-extended error
boundary and exit 1; `--traceback` is the diagnostic escape hatch.
