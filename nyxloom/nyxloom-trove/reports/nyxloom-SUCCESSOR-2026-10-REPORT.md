## Residuals / limits
- External-effect detection is heuristic (segment patterns, heredoc bodies dropped, wrappers stripped); a missed effect is possible, an over-match shows as a spurious "already done" line.
- `files read` paths are relativized against the transcript cwd, producing `../../../../tmp/...` for scratchpad files (cosmetic).
- The cursor comment appears twice in the successor document (once from the embedded extract, once at the end); either works for `--since-file`.
- Legacy `--show-tool-calls` aliases kept with a stderr note; `--follow` now also streams tool errors by default (`--tool-errors show` is the default).
- A user stop and a controller TaskStop are indistinguishable in the transcript text; only `.meta.json` `stoppedByUser` tells them apart, and the stop-state cause says so when the sidecar is missing.
- Claude Code adapter only (NL-31). No JSON form of ledger/stop state (NL-33). No redaction (decision): the extract can contain whatever the transcript contains.
- E-020's open items (restart, main-session Ctrl-C, cache repeat) are untested (NL-32).
- Intent fill-rate numbers in E-020 come from n=1 realistic pair; E-019 (earlier) measured 70.6% on different transcripts; both are prompt-dependent.
