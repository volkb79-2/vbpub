# Wings cgroups legacy workspace

This directory holds the host setup, design history, and test artifacts for
the Wings cgroup work. Its former `patchstack/` directory was consolidated
into the single canonical [`wings-patchstack/`](../../wings-patchstack/README.md)
layout.

For current patch metadata, pinned upstream commits, image provenance, and
workflow commands, use the [Wings patch-stack README](../../wings-patchstack/README.md)
and [consumer guide](../../wings-patchstack/CONSUMERS.md#apply-the-pinned-series).
The original deployed patch bytes remain in
[`wings-patchstack/archive/deployed-v1/`](../../wings-patchstack/archive/README.md).

The deployment procedure remains in [`SETUP.md`](SETUP.md); dated reports and
design notes in this tree describe the state at the time each was written.
