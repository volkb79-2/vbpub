# CIU changelog

All notable CIU changes are recorded here. Historical entries below were
reconstructed from the project-scoped git ranges and the released source. New
release entries are generated by CMRU from the same range before its release
gate runs; the commit subjects remain the traceable source of detail.

<!-- cmru: release history -->

## [4.11.1] - 2026-08-05

### Fixed

- Emitted Compose's `memswap_limit` field from CIU's `mem_swap_limit` policy,
  so the configured total memory-plus-swap limit is actually enforced.
- Made custom KSM shim validation fail closed for a missing file, directory, or
  broken symlink, while validating the logical path visible to CIU rather than
  the Docker-daemon-only physical path.

## [4.11.0] - 2026-08-04

### Added

- Added a global `[governance]` resource-policy default with shallow,
  last-wins stack overrides, preventing a partial stack policy from silently
  disabling governance.
- Added governance-aware cgroup placement for host development workloads and
  forwarded the dedicated background cgroup to CIU's tester gate.

### Fixed

- Made resource-policy resolution preserve the configured limits and fail
  loudly instead of falling through to Docker's unconfined default.

## [4.10.0] - 2026-08-03

### Changed

- Moved the CIU suite to the isolated `tester-unified` gate and enforced 100%
  total line and branch coverage.
- Strengthened multi-stack health classification and removed stale,
  unreachable orchestration paths exposed by the expanded gate.

### Added

- Added mutation-audit support for remote/liveness-sensitive behavior.

## [4.9.0] - 2026-07-30

### Fixed

- Hardened configuration rendering, secret materialization, host-directory
  provisioning, SSH transport, Docker-outside-of-Docker checks, and health
  handling across their failure paths.
- Preserved literal dollar-valued Compose environment data while retaining
  required-variable validation.

### Documentation

- Completed dispatcher and per-verb help coverage, plus configuration and
  operational guidance for the new surfaces.

### Testing

- Added regression coverage across config, secret, provisioning, transport,
  health, and failure behavior.

## [4.8.1] - 2026-07-27

### Added

- Added a named-systemd-slice governance preflight (D-G9), so an unknown slice
  cannot silently become an unbounded transient cgroup.

### Changed

- Warn on unknown governance keys while preserving forward compatibility with
  newer stack configurations.

## [4.8.0] - 2026-07-21

### Added

- Added Docker-optional remote activation: `ciu up --host <name> --thin`
  pushes a bundle and invokes the target's bootstrap/apply/health/rollback
  contract.
- Added KSM opt-in governance wiring and corrected per-profile compose/phase
  orchestration behavior.

### Fixed

- Applied `standalone_root` consistently to render operations and corrected
  stale physical-root detection in Docker-outside-of-Docker environments.
