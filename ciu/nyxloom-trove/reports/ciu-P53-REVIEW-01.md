**High — a first-allocation retry can accept a foreign Docker network.** Any failure in `_finish_allocation`, including an overlay publish failure before runtime ownership is established, is recorded as `env-generation-failed` ([worktree.py](/workspaces/vbpub/.worktrees/ciu-overlay-intent-20261013/ciu/src/ciu/worktree.py:4488)). On retry, that status alone sets `allow_existing_network`, bypassing the host-network collision refusal ([worktree.py](/workspaces/vbpub/.worktrees/ciu-overlay-intent-20261013/ciu/src/ciu/worktree.py:4816), [worktree.py](/workspaces/vbpub/.worktrees/ciu-overlay-intent-20261013/ciu/src/ciu/worktree.py:4428)). A network created by another owner between attempts can therefore be certified as ready. The tests cover a collision on initial create and a legitimate existing network on adopt, but not this harmful retry state ([test_ciu_worktree.py](/workspaces/vbpub/.worktrees/ciu-overlay-intent-20261013/ciu/tests/tests/test_ciu_worktree.py:1162), [test_ciu_worktree.py](/workspaces/vbpub/.worktrees/ciu-overlay-intent-20261013/ciu/tests/tests/test_ciu_worktree.py:3437)).
