## What draft.6 changed that a carver must know
- **State root (S2.6).** The checkout for a checkout; `<bundle_dir>/state/` for a release. Every mutable file lives there: `ciu.host.toml` (new; `[ciu.host]`; replaces `[ciu.host.generated]` inside the generated file), `ciu.instance.json` (now also the realness records), `ciu.secrets.toml`, receipts, `ciu-leases/`, `ciu-data/`, evidence, and — in a release — `stacks/<R>/ciu.state.toml`. Releases are byte-identical to their manifests for life. The generated file holds only `instance_id`, `owner_id`, build facts.
- **Activation (S17.4).** `ciu activate plan` writes `ciu.activation.json` (id + per-host expected release digest and selection); `apply` runs bootstrap (optional host hook) → **prepare** (CIU: host file + check in the target release) → apply → health → receipt → pointer switch; rollback is the same sequence for `previous`; pointers never move on failure. A consumer validates a provider's receipt against the manifest's entry **for the provider**. `plan_digest` and `--activation ID` are gone; `--activation-manifest FILE` replaces them.
- **Locks (S14.4.9).** Every mutator takes the stack lock of every Realization it touches (after instance and registry locks, sorted); a realization-only lease takes no instance lock; lease records are lock-free files; `CIU_LEASE_FDS` passes held descriptors to the leased command.
- **Moves (S4.1.2).** Cold only; refused while any resource carries the old owner; then new id + new token; `--fresh` for a copied tree; `adopt --owner` withdrawn.
- **Monorepo (S3.1.5, S6.2, S16.3).** `inherit` and `build.context` may leave a child root, never the containing worktree; `ciu.inherited.toml` flattened into a release; an inherited judge floor is unused without assay lanes. Fixture: `v8-dstdns-demo/examples/monorepo/`.
- **Gate.** Random 128-bit run ids with `run.json`; no `ciu gate --resume` (assay resumes itself); `memory_max` required for every admitted lane; host-network probes from the consumer's vantage with `probes` rows; `probe = "none"` on a binding for UDP host-network listeners.
- **Images (S17.6.1).** One reference-level image map; archive mode retags the verified id with a release-unique immutable reference; none mode compares ids before create.
- **Surfaces (S3.8.6).** The spec's enumerations are a tested output of the implementation (`ciu version --surfaces --json`); V8-1 owns that test.
