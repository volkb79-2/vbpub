# vmscreen CLI specification

Canonical command-line contract of the `vmscreen` console script. The generated grammar inventory between
the markers below is owned by `cli-extended surface sync`; everything else is product-owned. Reviewed semantic
decisions are in [`cli-review.toml`](cli-review.toml) and review findings in
[`cli-review-findings.toml`](cli-review-findings.toml). The surface is declared in
[`../pyproject.toml`](../pyproject.toml) (`[tool.cli-extended]`).

Exit codes (product contract): 0 ok, 1 other failure, 2 usage, 3 `wait-text` timeout, 4 no exact-text source applies
(graphical framebuffer), 5 QMP unreachable or erroring. With `--json` the failure object (`ok: false`, `error`,
`exit_code`, and `tried` / `last_text` where relevant) is printed to stdout as well.
