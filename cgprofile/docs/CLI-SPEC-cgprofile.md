# cgprofile CLI specification

Canonical command-line contract of the `cgprofile` console script, the end-user client: `run -- CMD` (direct
mode, needs cgroupfs), `mark`, `report`, `analyze` and the agent `skills` verbs. The generated grammar
inventory between the markers below is owned by `cli-extended surface sync`; everything else is
product-owned. The behavioural contract is [`CGPROFILECTL-SPEC.md`](CGPROFILECTL-SPEC.md) section 2.6;
reviewed semantic decisions are in [`cli-review-cgprofile.toml`](cli-review-cgprofile.toml) and review
findings in [`cli-findings-cgprofile.toml`](cli-findings-cgprofile.toml). The surface is declared in
[`../pyproject.toml`](../pyproject.toml) (`[tool.cli-extended]`). The socket client of the host daemon is a
separate executable, `cgprofilectl` ([`CLI-SPEC-cgprofilectl.md`](CLI-SPEC-cgprofilectl.md)).
