# cgprofilectl CLI specification

Canonical command-line contract of the `cgprofilectl` console script. The generated grammar inventory between
the markers below is owned by `cli-extended surface sync`; everything else is product-owned. The behavioural
contract is [`CGPCTL-SPEC.md`](CGPCTL-SPEC.md); reviewed semantic decisions are in
[`cli-review.toml`](cli-review.toml) and review findings in [`cli-review-findings.toml`](cli-review-findings.toml).
The surface is declared in [`../pyproject.toml`](../pyproject.toml) (`[tool.cli-extended]`).

The administrative daemon CLI `cgprofiled` is specified in
[`CGPCTL-SPEC.md` section 3](CGPCTL-SPEC.md#3-cgprofiled), including its `-t`
config-test option and repeatable `install --add-user LEVEL=USER` option.
A user named with `--add-user` must exist; recorded users whose accounts no
longer exist are dropped and reported on reinstall, which continues.
